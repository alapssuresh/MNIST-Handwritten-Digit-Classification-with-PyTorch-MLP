A deep learning project that builds and trains a Multi-Layer Perceptron (MLP) from scratch using PyTorch to classify handwritten digits from the MNIST dataset.
## Installation and Setup

### Prerequisites
- Python 3
- Conda (Anaconda or Miniconda), or pip

### Option 1: Using Conda

Create and activate a dedicated environment:

```bash
conda create -n covis_env python=3
conda activate covis_env
```

Install the required dependencies:

```bash
pip install tensorboardX torch matplotlib python-mnist tqdm
```

### Option 2: Using pip

If Conda is not installed, install the dependencies directly:

```bash
pip install tensorboardX torch matplotlib python-mnist tqdm
```

Once the installation is complete, the environment is ready to run the project.
